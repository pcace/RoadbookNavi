# RoadbookNavi Web Beta

## Plan and open roadbooks

Place waypoints on the map and select a routing profile. The five bundled Enduro
profiles are the same files used by the native apps. The web app uploads the
selected profile to brouter.de and sends your waypoints there for routing.
Address searches and place names use the provider selected in Settings.
Maps and intersection backgrounds come from OpenFreeMap.

Open existing Rally Navigator 2 (`.rn2`) files using **Open (.rn2)**. Export RN2
to continue editing in the native app, or download PDF, GPX and GeoJSON files.

## Storage and navigation

Projects stay in this browser on this device. There is no account or automatic
synchronization. Clearing website data or using private browsing can remove
projects. Export RN2 files to keep a backup.

New routes and map data need internet. Previously generated roadbooks can be
viewed while the app remains open without a connection; restarting the website
offline is not supported. GPS requires HTTPS and location permission. Keep the
app visible during navigation; background tracking is not guaranteed.

The downloadable native apps continue to calculate routes locally.
