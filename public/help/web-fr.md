# RoadbookNavi Bêta web

## Planifier et ouvrir des roadbooks

Placez des points de passage sur la carte et choisissez un profil de routage.
Les cinq profils Enduro fournis sont identiques à ceux des applications installées.
L’application web transmet le profil sélectionné et vos points de passage à
brouter.de pour calculer l’itinéraire. Les recherches d’adresses et de noms de
lieux utilisent le fournisseur choisi dans les paramètres. Les cartes et les
fonds des dessins d’intersections proviennent d’OpenFreeMap.

Ouvrez des fichiers Rally Navigator 2 (`.rn2`) avec **Ouvrir (.rn2)**. Exportez
un RN2 pour poursuivre la modification dans l’application installée, ou
téléchargez des fichiers PDF, GPX et GeoJSON.

## Stockage et navigation

Les projets restent dans ce navigateur sur cet appareil. Il n’y a ni compte ni
synchronisation automatique. Effacer les données du site ou utiliser la navigation
privée peut supprimer les projets. Exportez des fichiers RN2 pour les sauvegarder.

Les nouveaux itinéraires et les données cartographiques nécessitent Internet.
Les roadbooks déjà générés restent consultables sans connexion tant que
l’application est ouverte ; le redémarrage du site hors ligne n’est pas pris
en charge. Le GPS nécessite HTTPS et l’autorisation de localisation. Gardez
l’application visible pendant la navigation ; le suivi en arrière-plan n’est
pas garanti.

Les applications installées continuent de calculer les itinéraires localement.
