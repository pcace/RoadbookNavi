# FIA/Tulip symbol source

These symbols were generated by the [Tulip roadbook editor](https://gitlab.com/drid/tulip).
The matching upstream glyph catalogue and conversion tooling are documented in:

- <https://gitlab.com/drid/tulip/-/blob/master/GLYPHS.md>
- <https://gitlab.com/drid/tulip/-/blob/master/utils/convert_svgs.js>

The symbol directory is distributed separately from the RoadbookNavi application
code under the GPL-2.0 license in `LICENSE-Tulip`. Individual glyph attributions
from the upstream project are preserved in `GLYPHS.md`.

Upstream glyphs whose embedded metadata specifies `CC BY-NC-SA` are excluded from
this repository and from release bundles. This keeps RoadbookNavi distributions
free of noncommercial-only artwork. RN2 documents that reference an unavailable
glyph use the application's generic missing-symbol fallback.
